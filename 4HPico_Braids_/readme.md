Mutable Instruments Braids for the 4HPico DSP module

This implementation uses the ArduinoMI port of Braids. Its easier to use than Braids for the 2HPico because you can see which model you are selcting on the display.

April 2026 - quick port from 2HPico to 4HPico DSP hardware. its working but there are still things missing like using the extra CV inputs for modulation and some of the extended features of Braids like the scale quantizer.
